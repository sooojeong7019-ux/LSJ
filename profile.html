Game Designer Profile

Profile

게임의 세계관, 시스템, 레벨 구조, UI 흐름을 하나의 플레이 경험으로 연결하는 게임 기획 포트폴리오 프로필 페이지입니다. 이 영역은 자기소개, 지원 분야, 핵심 역량에 맞춰 자유롭게 수정할 수 있습니다.

기획 포지션

시스템 기획, 콘텐츠 기획, 레벨 디자인, UI/UX 기획을 중심으로 프로젝트의 플레이 흐름과 문서 구조를 설계합니다.

핵심 역량

  • 게임 메카닉스 구조화
  • 퀘스트 / 콘텐츠 플로우 설계
  • 레벨 동선 및 전투 배치 기획
  • 문서화 및 포트폴리오 구성

사용 툴

  • Unreal Engine 5
  • MS Word / PowerPoint
  • Figma 또는 UI 와이어프레임 툴
  • HTML / CSS 기반 포트폴리오 구성

Project Experience

Escape:Trauma 팀 프로젝트 기반 탈출형 공포 게임 기획 문서. The Stillborn Age 턴제 JRPG 개인 프로젝트. 세계, 전투, 탐험 구조 중심의 기획 문서. 레오나르의 날개 스팀펑크 RPG 개인 프로젝트. 레벨 디자인과 오픈월드 구조 중심의 기획 문서.
