각 폴더 안에 넣을 PDF 파일명:

02_story_scenario.pdf            = 게임 스토리 & 시나리오
03_character_concept.pdf         = 캐릭터 컨셉 기획서
04_background_concept.pdf        = 배경컨셉 기획서
05_game_mechanics.pdf            = 게임 메카닉스 기획서
06_game_content_system.pdf       = 게임콘텐츠시스템 기획서
07_level_design.pdf              = 레벨디자인 기획서
08_game_ui_design.pdf            = 게임UI디자인 기획서
09_game_service_plan.pdf         = 게임 서비스 기획서

HTML에서 각 문서는 아래처럼 id와 class로 분리되어 있습니다.

예시:
id="escape-development-proposal"
class="doc-card doc-card-01 doc-development-proposal"
data-doc-type="development-proposal"

따라서 나중에 특정 문서 카드만 수정하고 싶으면
각 프로젝트 HTML에서 해당 주석 또는 id를 검색하면 됩니다.
